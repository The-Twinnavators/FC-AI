# unDraw illustrations

Download SVGs from https://undraw.co/illustrations (free under the unDraw license; no attribution required) and
save them here with these names. They are bundled at build time and recoloured to FlowCode's tokens automatically
(keep unDraw's default accent `#6c63ff` when downloading).

| File | unDraw search | Used for |
| --- | --- | --- |
| `welcome.svg` | Welcome / Personal goals | Onboarding |
| `empty.svg` | Empty / Blank canvas / Add content | First run, no data |
| `no-results.svg` | Searching / Not found | Search and filters with no results |
| `security.svg` | Secure login / Two factor authentication | Auth and verification |
| `success.svg` | Celebrating / Completed | Task done, launch ready |
| `not-found.svg` | Page not found | 404 |
| `server-down.svg` | Server down / Maintenance | Daemon offline, 500 |
| `access-denied.svg` | Vault / Secure files | Permissions |
