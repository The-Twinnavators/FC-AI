# FlowCode starter — React + Vite + TypeScript (local-first)

Verified starter used by FlowCode's golden-path builds.

- `npm run dev` — local dev server
- `npm run typecheck` · `npm run lint` · `npm test` · `npm run build`

Design tokens live in `src/styles/tokens.css`; components use `var(--…)` only.
The design brief for QA is `.flowcode/design-brief.json`.
