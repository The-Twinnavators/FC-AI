# FlowCode starter: Angular + TypeScript (local-first)

Verified starter FlowCode uses when you start a build with Angular. Angular 21 with standalone components, signals and Vitest.

- `npm start`: local dev server
- `npm run typecheck`, `npm test`, `npm run build`

Design tokens live in `src/styles/tokens.css`; components use `var(--…)` only. Shared classes (`.shell`, `.button`, `.field`, `.panel`) are in `src/styles/app.css`. Each component keeps its `.ts`, `.html` and `.css` together.
